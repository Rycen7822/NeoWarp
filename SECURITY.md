# NeoWarp security policy

Report vulnerabilities in this fork to NeoWarp maintainers. Upstream Warp contacts do not manage this repository.

## Report a vulnerability

Do not publish exploit details, credentials, private logs, or a vulnerability reproduction in a public issue or
pull request.

Email the [repository owner](https://github.com/Rycen7822) at the public address shown on their GitHub profile.
Send only a contact request until the recipient confirms a private channel. A private channel is direct communication
that is not publicly visible, such as the confirmed email thread. Do not include vulnerability details in the first
request.

After confirming a private channel, include the affected version or commit, OS, impact, minimal reproduction, and
diagnostics with secrets removed. For SSH and WSL reports, identify the client and remote environments. Test only
on systems and data you control.
