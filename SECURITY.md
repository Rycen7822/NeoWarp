# NanoWarp Security Policy

Report vulnerabilities in this fork to NanoWarp maintainers. Upstream Warp contacts do not manage this repository.

## Reporting a Vulnerability

Do not publish exploit details, credentials, private logs, or a vulnerability reproduction in a public issue or pull request.

Use a private reporting channel listed by this repository's maintainers. If none is available,
[request a private contact](https://github.com/Rycen7822/NanoWarp/issues/new/choose) without including
vulnerability details or personal information. Wait for a confirmed private channel before sharing the report.

Include the affected version or commit, OS, impact, minimal reproduction, and diagnostics with secrets removed.
For SSH/WSL reports, identify the client and remote environments. Test only on systems and data you control.
